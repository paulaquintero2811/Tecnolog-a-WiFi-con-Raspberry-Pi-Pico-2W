Esta página controla el NRF24L01 conectado a la Raspberry Pi que aloja esta página.

Configuración de radio

Configura este Pico y configura el otro con los mismos canal y velocidad para que puedan comunicarse.

Importante para usar dos redes WiFi distintas

Abre la página de cada Raspberry desde un dispositivo conectado a su respectiva red WiFi. Configura ambos NRF24L01 con el mismo canal y velocidad; selecciona TX en uno y RX en el otro. La potencia puede ser diferente, aunque para una prueba controlada conviene usar el mismo valor.

Como el WiFi de las dos Raspberry está en redes diferentes, esta página no modifica automáticamente el segundo Pico: debes aplicar la configuración en la página alojada por cada uno.
